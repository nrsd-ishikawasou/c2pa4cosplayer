## 本書の位置付け

- 概要設計書 第13章（13-1〜13-4）を、基本設計の第1〜12章を対象に行う。この設計で目的（利用者の写真の権利を守る、抑止する）が達成されることを論証し、既知の破れを宣言する。
- 受ける決定は次の表のとおりである（設計計画書 第2版の決定・要調査・未決、および項目割りで見つけた抜け）。

|番号|種類|内容|
|---|---|---|
|D-2-3|決定|本システムの最大の価値は抑止とする（対応する要件はない。本システムの目的であり、2.2「抑止への効き方」で各章の効き方を論証する）|
|A-10|項目割りで見つけた抜け|設計計画書の決定から設計への対応表|
|全章|—|本書は全章の設計を検証の対象とする|

- 検証の方法：番号の対応（要件、決定、行き先表）は、文書から番号を機械的に抜き出して突き合わせた。場面・脅威・破れは、各章の本文をたどって確かめた。
- 設計計画書 第2版（2026-09-29）の改訂を受けている：本システムは利用者の情報を集めず、クライアントアプリの中で完結する。C2PA署名の証明書は端末で作り、認証局を要しない。権利者を装う者は排除できないものとし、照合の手がかりを示す。privateリポジトリを設けない。
- 記法：「【NRSD確認】」は、NRSD が確かめて決める事項を示す（6 に一覧）。

### 2.2 抑止への効き方

- 抑止は「転載すれば、権利者が誰かが分かり、証拠が残り、窓口に申し立てられる」と転載する側が知ることで働く。各章の寄与は次のとおり。

|知らせるもの|担う仕組み|章|
|---|---|---|
|権利者が誰か|可視署名（名前・識別番号）、C2PA署名の署名者、告知先アカウントの告知コード|第4章「画像編集と一括適用」、第3章「署名処理」、第2章「署名の情報と照合」|
|無断の利用が許されていないこと|同封文書（冒頭の一文 D-9-4「同封文書に、画像を他人に無断で授受してはならない旨の一文を入れる。その欠損は権利者の過失によるものではない」）、マニフェストの利用条件（cawg.metadata）、AI 学習の不許可（cawg.training-mining）、告知（C2PA の印の意味の説明を含む）|第5章「権利文書」、第3章「署名処理」|
|消しても追えること|不可視透かし（識別番号）、照合用ハッシュ|第3章「署名処理」|
|証拠が残ること|登録時の保全と時刻証明|第6章「登録と証拠保全」|
|申し立てられること|窓口とひな形、公開ページの案内|第7章「法的対応ガイダンス」、第8章「リポジトリとデータ管理」|
|見た目の良さで利用者が増えること（抑止の前提）|画面とデザイン|第10章「画面とデザイン」|

- 抑止の限界：C2PA署名が消える SNS（第3章 10.3「投稿先・Cloud での残存」）と、所在の分からない転載（第7章 5「運営者の特定」）では、抑止は可視署名と不可視透かしに依る。これは 4 で破れとして宣言する。

### 3.3 データの所在と責務

- 第1章 8.1「データの一覧」 のデータの一覧で、各データの生成元・保存先・公開の範囲・書き手が1つに決まっている。
- NRSD が持つのは、公開リポジトリの中身、更新・参照情報の鍵、コード署名の資格（Artifact Signing の署名の権限、Developer ID の証明書、公証の API の鍵）、香港のミラーの書き込みの鍵、GitHub の組織の所有者のアカウントのみ（第1章 8.5「秘密情報の一覧」）。利用者の情報・記録は NRSD に届かない（第8章 2.2「端末の外に出ないこと」）。指摘の電子メールは利用者が自分で送った場合にのみ NRSD に届く（第10章 9「指摘の受け口」）。

### 4.3 法務の論点

- 第12章 7「法務の論点（法務調査に置き、運営の判断の材料とするもの）」 の論点（非弁行為の整理、電子署名法の推定、証拠のための複製、電気通信事業に当たるか、指摘の電子メールについての国外の代表・代理人の要否、未成年の利用者、ライセンスと利用規約の優先の関係）は、法の要件を満たすことを設計では保証せず、NRSD の運営の判断に委ねる。
- 本システムは利用者の情報を集めない。NRSD が受け取るのは利用者が自分で送る指摘の電子メールだけであり、その扱いはプライバシーポリシーで公表する（第12章 5「プライバシーポリシー」）。国外の個人情報の法（中国の个人信息保护法、GDPR 等）は、この電子メールに限って運営の論点となる。
- 輸出管理は、公開の標準の暗号のみを使い、公開・無償で配ることで、日本では許可を要しない取引、米国では通知を要しないものとして扱い、リリースの都度確かめる（第12章 DD-12-8「公開の標準の暗号のみを使い、公開・無償で配る」）。
- 権利文書の文言は、専門家の確認を経てから配る（第12章 DD-12-10「権利文書の文言は専門家の確認を経てから配る」、設計計画書 9.5「準拠する法の考え方（参考）」）。確認を経ていない国は、全網羅のリンクのみで示す（第5章 4「文言の管理」）。

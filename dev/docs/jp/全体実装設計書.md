# 全体実装設計書（第16稿・2026-10-01）

## 本書の位置付け
- 仕様は設計書群（企画草案、設計計画書 第2版、概要設計書、基本設計 第1〜13章、調査、法務調査。日本語の md が正）。本書は仕様を写さず、ソースをどう組むかの索引（実装物、ブロックと依存、ブロックのページ、外部との境界、決めの所在）だけを書く。
- loop は1回。要求は設計書の改訂として受け、影響するブロックの段の状態を戻す（CLAUDE.local.md 0.12）。
- ブロックごとの設計（受ける節、依存、クラス図、橋、算法、データ設計）は ブロック/<ブロック>.md（本書と同じ dev/docs/jp/ の下。英語は dev/docs/en、中国語は dev/docs/cn に同じ構成で置く。日本語が正）。本書はその索引と、ブロックをまたぐ表（実装物、依存の辺、外部との境界）だけを持つ。決めごとは仕様の節に書き、5 はその所在の索引。

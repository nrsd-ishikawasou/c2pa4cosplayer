# シーケンス（入口ごとに、どこの何が呼ばれるかを全ルート追う）

- 入口＝画面の命令（app-client の B-280〜B-293）、起動、裏の待ち行列、OS からの受け取り（deep-link・落とされたファイル・回線の復帰）、相手の端末からの接続。
- 矢印の名前は各ブロックのページの「橋」の操作（`Block::op`、番号 B-）。ページに無い操作を要した時はページに足してから書く（それが抜け）。
- 失敗の分岐は、仕様の「失敗の扱い」の節に行がある事象だけを書く。
- 抜け（追って見つけた、ページにも仕様にも無いもの）は各ファイルの末尾「抜け」に、直した先（ページ・仕様の節）と一緒に書く。直さずに残さない。

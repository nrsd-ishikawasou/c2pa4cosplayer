由来：第1章 7（起動の順序、8つの状態）、7.8、9.3、第8章 4、第9章 4.1・4.4、第11章 3.1、第12章 4.3。

## S-01a 通常の起動（画面を出すまで。直列）
```mermaid
sequenceDiagram
  participant OS
  participant AC as app-client
  participant ST as core-store
  participant ID as core-identity
  participant RF as core-ref
  participant MK as core-mark
  participant UI as ui
  OS->>AC: 起動
  AC->>AC: CPU の確かめ（x86-64-v3。第11章 3.1）
  alt 対応しない
    AC->>OS: dialog「この PC の CPU には対応していません」→ 終了
  end
  AC->>AC: tauri-plugin-single-instance（9.3）
  alt 2つ目の起動
    AC-->>AC: 1つ目へ引数（写真・フォルダー）を渡して終了（S-01c）
  end
  AC->>AC: 自分自身を --crash-handler で子プロセスとして起動 → core-common CrashReport::init（第1章 10.3）
  AC->>ST: Paths::ensure_layout（B-020）
  AC->>AC: core-common Logging::init_logging(log_dir)、Clock::init(state_dir)（置き場は Paths から渡す）
  AC->>ST: RunMarker::last_exit_was_clean（B-026）
  AC->>ST: RunMarker::start
  AC->>ST: Settings::get（B-025。言語、表示）
  AC->>RF: Consent::consent_state（B-223）
  AC->>RF: Consent::terms_changed_since（規約の変更 → 再同意）
  AC->>ST: Schema::version_of / migrate（B-024。第9章 4.4）
  alt 移行に失敗
    AC->>AC: 状態 = 移行の失敗（読み取り専用）
  end
  AC->>RF: Store::minimum_version（B-224）
  alt 版が下回る
    AC->>AC: 状態 = 最低限の版未満
  end
  AC->>ID: IdentityStore::current（B-080）
  alt 無い
    AC->>AC: 状態 = 初回の前（S-02）
  else ある
    AC->>ID: Keystore::status（B-090）
    alt Linux で Secret Service なし
      AC->>UI: startup_prompt（合言葉の窓。第10章 3.6）
      UI->>AC: unlock_keystore（B-281）
      AC->>ID: Keystore::unlock
    end
    AC->>ID: IdentityStore::expiry_status（B-087）
    alt Stop20
      AC->>AC: 状態 = 20年超
    end
  end
  AC->>AC: 状態 = 通常 / 同意なし
  AC->>UI: 画面（B-295 webview_info を受け、get_startup_state B-280）
  Note over AC: ここまでが「10秒」の範囲（第1章 14.1）
```

## S-01d 閉じる・OS の終了（第9章 4.1）
```mermaid
sequenceDiagram
  participant OS
  participant UI as ui
  participant AC as app-client
  participant WK as core-work
  participant BK as core-backup
  participant ST as core-store
  UI->>AC: 閉じる（利用者の操作）
  AC->>AC: 一括処理・登録・控えの途中なら「今すぐ再起動して更新」は押せない
  AC->>WK: Sessions::autosave（B-141）
  AC->>BK: Scheduler::run_due（閉じる時の自動の控え）
  AC->>ST: RunMarker::clean_exit
  alt 更新の準備ができている
    AC->>AC: Updater::apply_on(Close)
  end
  OS->>AC: WM_QUERYENDSESSION / applicationShouldTerminate / ExitRequested
  AC->>WK: Sessions::autosave
  AC->>ST: state/update-pending の印（次の起動で画面の前に入れ替え）
  AC->>ST: RunMarker::clean_exit
```

## 抜け（追って見つけ、直した）
- 起動の直列の段に「規約の変更の確かめ」（第12章 4.3）が app-client のページの `Startup::run` の注記に無かった → app-client.md の `Startup` に `terms_changed_since` を足した（本ファイルの S-01a に沿う）。
- `state/update-pending` を置く時と読む時が app-client のデータ設計にだけあり、起動の直列（第1章 7）に「画面を出す前に入れ替える」の位置が無かった → 第9章 4.1 の OS の終了の項に「次の起動で、画面を出す前に」とあるので、第1章 7 の起動の順序の先頭に「`state/update-pending` があれば検証済みの配布物で入れ替える（第9章 4.1）」を足した。
- 裏の待ち行列の最後の「期限の知らせ」（第7章 6.3 の起動していなかった分）が第1章 7 の裏の順に無かった → 第1章 7 の裏の順の末尾に足した。

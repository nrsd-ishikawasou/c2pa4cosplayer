## S-12b この端末の記録を消す（第9章 2.3）
```mermaid
sequenceDiagram
  participant UI as ui
  participant AC as app-client
  participant BK as core-backup
  participant SY as core-sync
  participant ID as core-identity
  participant ST as core-store
  UI->>AC: wipe_device（B-290）
  AC->>BK: Settings（最後の控えの日時。無い・古ければ「控えを作る」を先に）
  AC-->>UI: RetentionNotice（請求の期間）と確かめの窓（消えるもの・消えないもの、確認の語）
  UI->>AC: wipe_device(confirm_word)
  AC->>ID: OsAuth::os_user_verify（B-092）
  AC->>SY: Link::announce_removed（「この端末を外した」の行。届かなければ他の端末で手で外す）
  AC->>ID: Keystore::wipe_keys（B-090。署名鍵と端末の鍵）
  AC->>ST: Paths::data_dir / cache_dir / log_dir を消す（B-020。Windows は EBWebView、macOS は WebKit のデータ）
  AC-->>UI: 失敗した項目の一覧 → 終了（次の起動は初回）
```

## 抜け（追って見つけ、直した）
- お知らせの既読が「端末に依らない設定」（第10章 10 の保存の項）なのに、app-client のデータ設計では `state/read-notices.json`（端末ごと）にしていた → `settings.json` の `notices.read`（端末に依らない）に改め、app-client.md のデータ設計の行を直した。
- 「この端末を外した」の行の送り先（core-sync の操作名）が core-sync のページに無かった → core-sync.md の `Link` に `announce_removed()`（devices の連鎖の行として送る）を足した。

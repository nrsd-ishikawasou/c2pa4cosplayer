# 整体实现设计书（第16稿・2026-10-01）

## 本书的定位
- 规格为设计书群（企划草案、设计计划书 第2版、概要设计书、基本设计 第1〜13章、调查资料、法务调查。以日文的md为准）。本书不抄写规格，只写源码如何组织的索引（实现物、区块与依赖、区块的页面、与外部的边界、决定的所在）。
- loop为1次。要求作为设计书的修订接受，并回退受影响区块的阶段状态（CLAUDE.local.md 0.12）。
- 各区块的设计（承担的节、依赖、类图、桥、算法、数据设计）在 区块/<区块>.md（与本书同在dev/docs/cn/之下。日文原文在dev/docs/jp，英文在dev/docs/en，构成相同。以日文为准）。本书只持有其索引与跨区块的表（实现物、依赖的边、与外部的边界）。决定写在规格的节中，5为其所在的索引。

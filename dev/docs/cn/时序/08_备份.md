## S-08a 创建（手动B-240 create、自动run_due、关闭时）
```mermaid
sequenceDiagram
  participant AC as app-client
  participant BK as core-backup
  participant ID as core-identity
  participant ST as core-store
  participant SG as core-sign
  participant HS as core-hash
  participant UI as ui
  AC->>AC: 保证没有导出・登记的中途处理（第8章 5.2 顺序2）
  AC->>BK: Scheduler::run_due(now, changed) / Writer::create(dest, passphrase, kind, since)（B-240）
  BK->>BK: Destinations::list（仅可达的存放处。Device为app-client以core-sync的backup_folder连接的）
  BK->>ID: OsAuth::os_user_verify（B-092）
  BK->>ID: Keystore::export_keys（B-091。keys/）
  BK->>ST: Chain::read（B-022。前次manifest以后的行。整体则全部）
  BK->>SG: Works（原图的差分。Cloud的存放处不含原图）
  BK->>ST: SafeArchive::zip_write（B-027。逐次）→ age（恢复密钥的公钥。附件为以口令包裹的秘密密钥）
  BK->>ST: AtomicFile（临时名称 → 重新读取并与manifest.json的SHA-256核对 → 正式名称）
  BK->>ST: Settings::set(backup.last_at)（B-025）
  AC-->>UI: progress / notice（“最后的备份：〇分钟前”）
  alt 没有任何存放处可达
    BK->>BK: unreachable_days（7天时UI notice）
  end
```

## S-08b 恢复（G-06）
```mermaid
sequenceDiagram
  participant UI as ui
  participant AC as app-client
  participant BK as core-backup
  participant CM as core-common
  participant ST as core-store
  participant ID as core-identity
  participant WK as core-work
  UI->>AC: restore_backup(path, secret, merge)（B-282）
  alt 恢复密钥的QR
    UI->>AC: decode_recovery_qr(image) → core-image Decoder::validate_image（20MB・8,000像素。第1章 10.10）→ decode → CM Qr::decode(pixels)（B-013）
  end
  AC->>BK: Reader::restore(path, secret, merge_policy)（B-241）
  BK->>BK: Reader::open（age的头部。超过scrypt 2^22则拒绝）
  BK->>ST: SafeArchive::zip_read（B-027。解压的合计与一览的一致）
  BK->>ST: Schema::validate(manifest.json)（B-024。比自身新的版本则“催促更新”）
  BK->>BK: 把各文件的SHA-256与一览核对（差分从full起按seq的顺序、parent_sha256的连锁）
  BK->>ID: IdentityStore::current（B-080。个人根证书的比较）
  alt 没有记录
    BK->>ID: Keystore::import_keys（B-091）
    BK->>ST: 解压到临时位置 → Chain::verify（B-022）→ 到正式位置
  else 同一个人根证书
    BK->>ST: Chain::merge_rows（B-022。对齐方法依第1章 8.3）
    BK->>WK: Merge::merge_remote(templates, sessions)（B-151。第4章 8.2）
  else 不同的个人根证书
    BK-->>AC: 选择（创建备份后替换 / 放弃）→ UI 确认的窗口
  end
  AC-->>UI: RestoreReport（件数、未通过的记录）
```
